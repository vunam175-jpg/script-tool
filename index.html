Bước 1: Viết kịch bản

Chọn loại dòng (Scene, Action, Character, Dialogue...) và nhập nội dung. Kịch bản được định dạng tự động theo chuẩn điện ảnh. Dùng mẫu phim ngắn để hiểu cấu trúc.

🎬

Bước 2: Lên Shot List

Phân tích từng cảnh thành các shot cụ thể: loại shot (CU, MS, LS...), góc máy, chuyển động camera. Xuất ra CSV để mở trong Excel/Google Sheets.

🎨

Bước 3: Tạo Storyboard

Thêm panel, nhập mô tả, dùng AI tạo ảnh tự động. Hoặc chuyển đổi trực tiếp từ Shot List. Có thể upload ảnh thủ công hoặc dùng AI tạo.

⚙️ Về các nhà cung cấp AI

🌼 Pollinations.ai (Mặc định)

Miễn phí 100%, không cần đăng ký, không cần API key. Chất lượng khá, tạo ảnh nhanh. Phù hợp cho hầu hết nhu cầu storyboard.

🔮 Google Gemini / Imagen 3

Chất lượng cao nhất, hiểu ngữ cảnh tốt. Cần API key từ aistudio.google.com/apikey. Có chi phí (~$0.03/ảnh).

🤗 Hugging Face

Đa dạng model ảnh (SDXL, FLUX...). Cần token từ huggingface.co/settings/tokens. Có gói miễn phí giới hạn.

💡 Mẹo viết prompt tạo ảnh tốt

  • Chỉ rõ loại shot: "Close-up", "Medium shot", "Wide shot", "Over-the-shoulder"
  • Góc máy: "Low angle", "High angle", "Eye level", "Dutch angle"
  • Ánh sáng: "Cinematic lighting", "Backlight", "Soft diffused light", "Harsh shadows", "Golden hour"
  • Phong cách: "Storyboard sketch", "Cinematic", "Film noir", "Anime style", "Black and white"
  • Tỷ lệ khung hình: Thêm "16:9" cho phim ngang, "9:16" cho phim dọc (vertical micro-drama)

⚙️ Cài đặt AI

Lấy key tại: aistudio.google.com/apikey

Lấy token tại: huggingface.co/settings/tokens

🔒 Bảo mật: API key và token chỉ được lưu trên trình duyệt của bạn (localStorage), không bao giờ gửi đến server nào khác. Nếu bạn share link GitHub Pages cho người khác, họ sẽ cần nhập key của riêng họ.
