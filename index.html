Tự tạo tool kịch bản trên GitHub

Hoàn toàn MIỄN PHÍ với GitHub Pages. Xây dựng bằng HTML/CSS/JS thuần, lưu dữ liệu trên trình duyệt (localStorage), không cần server, không cần database. Dưới đây là hướng dẫn + tool demo hoạt động được.

1

Tạo repo GitHub

  1. Đăng nhập GitHub → New repository
  2. Đặt tên: script-tool
  3. Chọn Public → Add README → Create
2

Upload file HTML

  1. Trong repo → Add file → Upload files
  2. Tải file index.html (copy code từ tab "Code template")
  3. Commit changes
3

Bật GitHub Pages

  1. Settings → Pages (ở sidebar trái)
  2. Source: chọn Deploy from a branch
  3. Branch: main / /root
  4. Save → đợi 1-2 phút
  5. Truy cập: https://[username].github.io/script-tool

Những gì có thể làm miễn phí

✓ Viết kịch bản

Định dạng tự động Scene Heading, Action, Character, Dialogue, Parenthetical

✓ Lên shot list

Shot number, shot type, góc máy, mô tả, thiết bị, ghi chú

✓ Storyboard cơ bản

Lưới các ô, upload ảnh, mô tả hành động, thoại

✓ Lưu & xuất

Lưu localStorage, xuất JSON, in/PDF, import/export

✓ Tích hợp AI

Dùng API miễn phí (Gemini Free tier, Hugging Face) để gợi ý kịch bản

✓ Đa dự án

Chuyển đổi giữa các kịch bản, quản lý nhiều dự án

Giới hạn cần biết

  • Dữ liệu chỉ trên trình duyệt: localStorage không đồng bộ giữa các thiết bị. Giải pháp: thêm tính năng Export/Import JSON.
  • GitHub Pages chỉ static: Không chạy PHP/Node/Python. Nhưng JS thuần đủ mạnh cho 90% nhu cầu.
  • AI image gen: Storyboard tự động cần API key (có thể dùng Gemini Free tier 15 yêu cầu/phút).
  • Giới hạn dung lượng: GitHub repo 1GB, Pages 1GB băng thông/tháng - rất dư cho tool kịch bản.
